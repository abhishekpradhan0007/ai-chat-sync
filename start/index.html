Getting started

Two minutes from here to your first synced conversation.

Your licence key is on your Lemon Squeezy receipt and on the order page. Keep it — you will need it in step 3.

1. Install

The Chrome Web Store listing is still in review. Until Google approves it, install the build below directly — it is the same extension, and your licence works with it. We will email you the Web Store link the moment it is live so you can switch over and get automatic updates.
  1. Download the extension and unzip it somewhere you will keep — not the Downloads folder, since Chrome loads it from wherever it sits.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Pin the icon to your toolbar.

Chrome will show a "developer mode extensions" notice on startup while it is installed this way. That stops once you move to the Web Store version.

2. Choose where chats are saved

Click the icon, then Choose save folder / settings, and pick your Obsidian vault root — not a subfolder.

Conversations are written to AI Chats/carry-backup/<platform>/ inside it, and those folders are created for you. The extension can only ever touch the folder you grant here, and you can revoke that access at any time.

3. Activate your licence

Go to Settings → Licence, paste your key, and press Activate. The banner changes to “Licensed to your@email”.

Your key is checked with Lemon Squeezy when you activate it, and rechecked about once a week so refunds take effect. Only the key is sent — never any conversation content, titles or file paths.

4. Pull in what you have already written

On a Claude, ChatGPT or Grok tab, click Back up all. This walks your entire history on that platform, not just the tab you have open. It takes a few minutes — leave the popup open.

Migrating from another tool? If conversation notes are already in that folder, use Index notes already in this folder in Settings. It reads what is there and adds it to your Memory Home without re-downloading anything.

5. Let it run

Background sync is on by default. It saves new and changed conversations on your schedule and skips anything unchanged, so your vault stays quiet.

What lands in your vault

Each conversation becomes a Markdown note with YAML frontmatter: source, title, tags, category, topics, real provider timestamps and a content hash. Topics become real [[wikilinks]], and an AI Memory Home page indexes everything with a hub for each recurring theme.

From Claude you also get artifacts saved as openable files, conversation attachments, and project instructions and documents.

What it does not do

Worth knowing up front rather than discovering later:

  • Perplexity is beta. The thread is captured, but citations are not — Perplexity renders them with JavaScript rather than as links.
  • DeepSeek, Copilot, Mistral, Qwen and Meta AI are not supported yet.
  • Chats that never reach the web app cannot be captured — ChatGPT Temporary Chats, Claude incognito chats, and local Codex or Cowork sessions are not visible to Chrome.

If something is not working

Click Diagnostics on the page that is misbehaving. It reports exactly which parts work and which do not. Send that output to abe@pipelineedge.in and it usually tells us exactly what to fix. Please do not send confidential conversation text.
