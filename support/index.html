Quick setup

  1. Open Abe AI Sync and select your Obsidian vault root or another folder you control.
  2. Open a supported conversation on ChatGPT, Claude, Gemini, Grok, or Perplexity.
  3. Select Sync this conversation, then confirm that the Markdown note appears under AI Chats/.
  4. Use Back up all only on a supported provider page. Background sync is optional.

Common issues

“Not a supported AI chat site”

Switch to an actual conversation tab before running Diagnostics or Back up all. Chrome settings pages, the extension's own Settings page, new-chat home pages, and unsupported provider pages cannot be captured.

“No conversation found on this page”

Open an existing conversation and wait until its messages have loaded. If the provider has just changed its website, reload the page and retry once. If the error continues, send the provider name, page URL without private query data, extension version, and Diagnostics text to support.

The save folder is disconnected

Open Settings and choose the folder again through Chrome's folder picker. The extension can write only inside the folder you explicitly grant.

Desktop-app conversations are missing

Ordinary ChatGPT and Claude desktop conversations may be available after they appear in the same account's web history. Temporary chats, incognito sessions, Codex or ChatGPT Work sessions, and Claude Code or Cowork sessions that never appear on the provider website are not captured in version 1.

Supported coverage

Open-conversation capture is available for supported pages on ChatGPT, Claude, Gemini, Grok, and Perplexity. Full-history backup is currently offered for ChatGPT, Claude, and Grok. Provider changes can temporarily affect capture.
